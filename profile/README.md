# Norlay

**Turning real problems into better technology.**

Norlay is an independent software brand by Yousef Elbanna.

## Products

### Norlay Assistant

One desktop app for macOS and Windows. Version **27.1.0** is available and has been tested by the owner on both platforms.

- [Product information](https://norlay.fit/norlay-assistant/)
- [What's new](https://norlay.fit/whats-new)
- [Installation help](https://norlay.fit/norlay-assistant/docs/)
- [Downloads](https://norlay.fit/downloads)

### Norlay Link Checker

A separate Windows NVDA add-on. Its source and releases are maintained in [NorlayOfficial/norlay-link-checker](https://github.com/NorlayOfficial/norlay-link-checker).

### Norlay Code

Norlay Code was discontinued before public release and has no download or support.
